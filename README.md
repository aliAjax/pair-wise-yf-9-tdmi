# 桌游规则遗忘点卡片库 · 开局讲解单

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒，并在聚会当晚按到场朋友生成讲解单。

## 功能

- **朋友熟练度**：给常来的朋友记录每款桌游的熟练度（没玩过 / 玩过 / 熟悉），未记录的默认没玩过。
- **今晚名单**：在游戏详情里勾选到场朋友，名单按游戏保存，下次打开接着用。
- **讲解单**：只列出场上最不熟的人会漏掉的提醒，按 容易忘的规则 → 常见争议 → 开局准备 → 计分提醒 四类顺序排列，讲完一项勾一项。
  - 每条规则卡片带"谁会漏"等级：仅新手会漏 / 玩过也会漏 / 老手也会漏，添加时可调整。
  - 有人讲完才到：勾上他之后，他会漏掉的已讲项自动重新打开，不会留在完成记录里。
  - 有人离场：取消勾选后，只为他的熟练度保留的多余项连同完成记录一起收走。
- **游戏库**：按最近未玩、人数范围和复杂度筛选，支持封面图、规则卡片增删。

朋友资料、讲解状态和上次名单都只存在浏览器 localStorage，不上传任何数据。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
