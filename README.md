# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒，并为周末临时组局生成「今晚讲解单」。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 核心功能

### 桌游收藏与四类提醒卡

按最近未玩、人数范围和复杂度筛选收藏；每款游戏维护四类提醒，顺序固定为：

1. 容易忘的规则
2. 常见争议
3. 开局准备
4. 计分提醒

### 朋友熟练度

在名单面板添加常来的朋友，在每款游戏详情里记录其熟练度：

- **没玩过**：四类提醒全部要讲
- **玩过**：跳过「开局准备」，其余三类要讲
- **熟悉**：无需讲解

未记录熟练度的朋友默认按「没玩过」处理。

### 今晚名单与讲解单

点亮名单上的朋友表示到场。每款游戏的讲解单只按**场上最不熟的人**生成，并展示进度（已讲 n/总数）。讲完一项打勾即可。

- **讲完才到**：迟到的朋友点亮到场时，如果他不比原来最不熟的人更熟（持平或更生），他会漏掉的已讲项会自动取消勾选、标红「迟到重开」，不会混进完成记录；比场上都熟的人迟到则不影响讲解单。
- **离场**：再点一次名单即离场，讲解单按剩余人重算，因他而存在的多余项自动收走，完成记录只保留当前清单上的勾选。
- 详情里可随时「重置讲解勾选」；名单面板可「清空名单」（同时重置全部勾选），下场聚会从头再来。

## 数据存储

朋友资料、每款游戏的熟练度、讲解勾选状态和上次名单都保存在浏览器 `localStorage`（键名 `zfl18-boardgame-rule-cards`），下次打开页面自动恢复。「迟到重开」的红色高亮只在本次页面会话内提示，不会写入存档。
